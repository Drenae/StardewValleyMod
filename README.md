# DrenaeMod

DrenaeMod est un mod graphique pour Stardew Valley basé sur SMAPI et Content Patcher.

## Objectif

Refaire progressivement l'identité visuelle de Stardew Valley sans modifier directement les fichiers originaux du jeu.

Le projet pourra notamment inclure :
- bâtiments de la ferme ;
- maisons et bâtiments du village ;
- mobilier et décoration ;
- éléments de décor ;
- autres textures du jeu selon l'avancement.

## Prérequis

- Stardew Valley 1.6+
- SMAPI 4.x
- Content Patcher 2.x

## Structure

```text
DrenaeMod/
├── assets/
├── content.json
└── manifest.json

docs/
└── ROADMAP.md
```

## Développement

Les ressources originales de Stardew Valley extraites localement ne doivent jamais être ajoutées au dépôt.
Seuls les fichiers créés ou modifiés pour DrenaeMod doivent être versionnés.
